# Virtual Try-On Clothes Project (Flask)

This is an AI-powered virtual try-on web application built using Flask. It lets users upload a personal image and see how different clothes look on them in real-time using Pixelcut API.

## Features:
- 👤 User Signup/Login System
- 🛡️ Admin Dashboard to manage users
- 👕 Virtual Try-On Integration (Pixelcut API)
- 📂 Image Upload with result preview
- 💾 MySQL Database support

### 🔧 Tech Stack:
- Python + Flask
- HTML/CSS/Bootstrap (Frontend)
- MySQL (Database)
- Pixelcut API

> Built for a university project to demonstrate the power of virtual fashion try-on using AI.
